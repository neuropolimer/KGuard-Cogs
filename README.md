# KGuard-Cogs

Приватный репозиторий сторонних cog'ов для Red-DiscordBot 3.5.x на Python 3.11.

## TempVoice

`tempvoice` создаёт временную голосовую комнату, когда пользователь входит в настроенный канал-генератор, переносит пользователя внутрь и удаляет комнату после полного опустошения.

Возможности:

- несколько независимых генераторов со своими категориями и шаблонами;
- наследование прав от категории при создании;
- сохранение генераторов, временных комнат и владельцев через `redbot.core.Config`;
- восстановление tracked-комнат после перезапуска Red;
- автоматическая передача владельца следующему пользователю;
- защита от повторного создания и параллельных событий;
- удаление только каналов, записанных cog'ом как временные;
- переименование, лимит, блокировка, скрытие, персональные разрешения и отключение участников.

При первом запуске cog автоматически добавляет следующие генераторы на сервере, где существуют указанные каналы и категории:

| Creator channel | Category | Шаблон |
|---|---|---|
| `1540378275438665739` | `1540377033794912397` | `🔊 Канал {nick}` |
| `1540379320076337253` | `1540357744618508289` | `🔊 Канал {nick}` |

## Установка

Репозиторий приватный, поэтому сначала настройте на машине Red read-only SSH deploy key, как описано ниже. После этого выполните в Discord от владельца бота:

```text
[p]load downloader
[p]repo add KGuard-Cogs git@github-kguard:neuropolimer/KGuard-Cogs.git
[p]cog install KGuard-Cogs tempvoice
[p]load tempvoice
```

Проверка конфигурации:

```text
[p]tempvoiceset list
```

## Обновление

```text
[p]cog update tempvoice
[p]reload tempvoice
```

## Команды владельца комнаты

Команды работают только внутри временной комнаты и только для её текущего владельца.

| Команда | Назначение |
|---|---|
| `[p]vc rename <название>` | Переименовать комнату |
| `[p]vc limit <0-99>` | Задать лимит; `0` — без ограничения |
| `[p]vc lock` | Запретить `@everyone` подключаться |
| `[p]vc unlock` | Восстановить Connect по правам категории |
| `[p]vc hide` | Скрыть комнату от `@everyone` |
| `[p]vc show` | Восстановить View Channel по правам категории |
| `[p]vc permit @user` | Явно разрешить просмотр и подключение |
| `[p]vc reject @user` | Запретить подключение и отключить участника |
| `[p]vc kick @user` | Отключить без постоянного запрета |

## Администрирование

Команды доступны владельцу сервера, владельцу Red и администраторам Red/Discord.

| Команда | Назначение |
|---|---|
| `[p]tempvoiceset list` | Показать генераторы |
| `[p]tempvoiceset add <creator_channel> <category> <template>` | Добавить генератор |
| `[p]tempvoiceset remove <creator_channel>` | Удалить генератор из настроек |
| `[p]tempvoiceset template <creator_channel> <template>` | Изменить шаблон |

Шаблон должен содержать `{nick}`. В аргументах можно использовать упоминания или ID каналов.

## Необходимые права бота

- View Channel;
- Connect;
- Manage Channels;
- Move Members.

Права должны действовать в обоих каналах-генераторах и в категориях временных комнат. Роль бота должна находиться выше ролей участников, которых требуется перемещать.

## Безопасный доступ к приватному репозиторию

Используйте отдельный SSH deploy key только для этого репозитория и выдайте ему read-only доступ. Не используйте GitHub PAT в команде `[p]repo add`: сообщение Discord и remote URL локального клона могут сохранить токен.

Пример `~/.ssh/config` на хосте Red:

```sshconfig
Host github-kguard
    HostName github.com
    User git
    IdentityFile ~/.ssh/kguard_cogs_ed25519
    IdentitiesOnly yes
```

Публичную часть ключа (`kguard_cogs_ed25519.pub`) добавьте в GitHub: **KGuard-Cogs → Settings → Deploy keys → Add deploy key**, без флажка write access. Приватная часть остаётся только на сервере Red.
